1. 対象と基本方針

このポリシーは、A. Chrome拡張機能「GridPorter」がブラウザー内で処理するWebデータ、B. 利用者自身が任意にサポートへ送るお問い合わせ、および本公式Webサイトの情報の取扱いを分けて説明します。GridPorterの目的は、利用者が選択したWebの表・一覧を取得し、確認・整理してExcelなどへ出力することです。

GridPorter ExtensionはLocal-firstを基本とし、抽出したWebデータ・ページURLを開発者サーバーへ自動送信しません。GridPorterが取得したWebデータを外部AIサービスへ送信せず、開発者クラウドへ自動保存しません。Extensionにはアカウント登録、Analytics SDK、広告はなく、取得データを販売しません。任意のお問い合わせの処理は、後述のサポートに関する節で説明します。

GridPorterは、Chrome Web StoreのUser Data Policy（Limited Use要件を含む）に従い、利用者の情報の利用を、ここに開示した表・一覧の取得・確認・整理・出力と関連する機能の提供・改善に限定します。閲覧履歴全体を追跡する目的では利用しません。広告配信、データ仲介、信用評価や融資のために情報を利用・移転・販売しません。

2. A. Extensionが取り扱う情報と保存目的

利用者の操作に応じ、次の情報をブラウザー内で処理します。選択したページの情報には個人情報や業務上の機密情報が含まれる場合があります。

情報内容と利用目的保存場所
Website content選択した表・一覧の文字、リンク・画像URLと代替文字、一部非機密フォームの現在値。取得・編集・出力に使用。画像本体は収集しません。処理中のメモリー、Dataset
URL・タイトル取得元の識別、ページ送り、Recipeの再利用、任意の取得情報シートに使用。Dataset、Recipeなどの関連データ
RecipeURL条件、取得条件・セレクター、列・整形設定、Repair用の列名や見出し等の署名。繰り返し作業に使用。chrome.storage.local
Dataset取得行・列、編集前の元データなど。プレビュー・編集・出力に使用。IndexedDB。保存しない設定ではchrome.storage.session

パスワード・hidden入力や認証を示す入力などを取得対象から除外します。ただし一般の表や入力欄に含まれる機密情報を自動で検出・除去できることを保証しません。

3. Extension内の保存期間と削除方法

抽出データと途中結果

  • Datasetは「保存しない・1日・7日」から選択でき、既定は7日です。「保存しない」場合もプレビュー用にセッションストレージへ全体8MBまで一時保持し、表示中の画面にもメモリー上のデータが存在します。
  • セッションのデータはブラウザー再起動や拡張機能の無効化・再読み込み等で失われ得ます。「保存しない」はデータの即時消去を意味しません。
  • checkpointは1日、最大10件・全体20MBです。「保存しない」設定では永続保存しません。
  • 期限判定は利用時・起動時に行います。ブラウザーを使用していない間の指定時刻での消去を保証しません。
  • 保存期間短縮の確認時に期限超過分を削除します。「保存しない」に変更すると既存の永続Dataset・checkpointを削除します。

比較履歴は別管理です

任意保存のSnapshotは「30日・90日・365日・削除するまで」から選択でき、既定は90日です。Recipeごとに最大5件、1件20MB・全体40MBです。容量超過時は保存を拒否し、比較基準を容量整理のために自動削除しません。期限判定は比較・履歴の利用時に行い、期限が過ぎた基準は削除対象になります。

Datasetの「保存しない」や削除操作はSnapshotに影響しません。比較履歴の管理画面で個別削除・全削除・保存期間変更ができます。期間短縮では期限超過の基準も削除されます。旧Snapshotの期限を移行時に自動延長しません。

手動削除と出力済みファイル

設定画面で一時取得データ（Dataset・checkpoint・セッション）と比較履歴をそれぞれ削除でき、両方を削除する操作も別途確認します。RecipeはRecipe管理から削除できます。Recipe・設定・ローカル利用カウンターは手動削除できる項目を除き、拡張機能のアンインストールまで端末内に保持します。

任意設定の「Excel/CSV保存後に抽出データを削除」は保存完了後にDataset・checkpointを削除します。Recipe・Snapshot・開いているプレビューのメモリー・ダウンロード済みファイルは消しません。開いているプレビューは作業後に閉じ、出力ファイルや貼り付け先のデータは利用者自身で管理・削除してください。

4. Extensionの送信・共有と対象サイトへの通信

開発者への自動送信はありません

抽出内容・URL・Recipe・Dataset・Snapshotを開発者や広告・分析事業者へ自動送信しません。開発者は端末内の抽出データを閲覧できません。データを第三者に販売せず、広告目的で共有しません。

対象Webサイトへの通常通信

次ページの取得は、利用者が指定した同一サイトへの通常のGET通信を行い、対象サイトのセッションを利用します。「もっと見る」ボタンやスクロール操作は、対象サイト自身の通信を発生させる場合があります。Cookie値を取り出して保存する機能ではありません。対象サイトによる情報の取扱いは、そのサイトの方針をご確認ください。

出力・Recipe転送・サポートでの明示的な共有

XLSX・CSV・コピーは利用者の明示操作で作成します。任意の取得情報シートにはタイトル・URLパス等、差分シートには変更前後の値が入り得ます。Google Sheets等への貼り付け先やファイルの共有先では、そのサービスの方針が適用されます。

RecipeのImport / Exportは利用者が指定したファイル操作です。URL・セレクター・列名・見出しなどに業務情報が含まれ得ます。共有前に内容を確認してください。Import直後の自動取得は行いません。Repair用の情報も端末内に保持します。

サポート情報は利用者が明示的にコピーし、共有先を選びます。バージョン、取得モード、終了理由、行列数、診断コード、境界種類等を含み、本文・セル値・Cookie・認証値・セレクター文字列は含みません。URLは利用者が選択した場合のみ入り、認証情報・クエリ・フラグメントを除外します。ただしパス自体にも機密情報が含まれる場合があります。

Extension内のデータが、問い合わせとして自動送信されることはありません。サポートへメールやファイルを送る場合は、利用者自身が内容と送信先を選んで送信します。以下の取扱いが適用されます。

5. B. 利用者が任意に送るお問い合わせ

扱う情報と目的

利用者自身がサポートへメールを送った場合に限り、送信者メールアドレス、件名、本文、添付資料、その他本文中で提供された情報を取り扱います。これらはGridPorter Extensionから自動収集・自動送信されるものではありません。

お問い合わせへの回答、不具合調査、セキュリティ調査、GridPorterとサポートの品質改善に必要な範囲で利用します。運営者は、この目的に必要な範囲で問い合わせ内容や添付資料を確認します。広告・ターゲティング、データ販売・仲介、信用評価・融資、無関係なマーケティング、外部モデルの学習・ファインチューニング、公開データセットには利用しません。

GmailとGoogle Driveでの処理

問い合わせの送受信・保存にはGoogle Gmailを利用します。対応を補助する仕組み（ContactSupporter）では、Google Apps Scriptによる処理で件名・本文の一部を最小限に絞り、専用の非共有Google Drive処理領域へ一時保存する場合があります。この処理用コピーには、メールアドレス・電話番号・住所・認証情報・秘密情報等の自動マスキングを行います。送信者メールアドレスの欄は、運営者端末でのローカル解析用キューには含めません。

自動整理を行う場合は、件名が所定の製品識別子で始まる問い合わせを対象とします。その他のメールもGmailで受信しますが、自動整理の対象外となる場合があります。

自動処理前に一部の個人情報・秘密情報をマスキングする措置を行いますが、完全な匿名化を保証するものではありません。自然文の氏名・会社名、未知の形式の秘密情報などが残る可能性があります。Gmailの原文にこの処理を適用して書き換えるものでもありません。秘密情報は送らないでください。

添付資料の取扱い

添付資料はGmailで受信します。現在の自動処理は、添付の有無とMIME種類のみを扱い、添付内容を取得せず、ファイル名をローカルAIへ渡さず、ファイル本体をDriveの処理キューへコピーしません。必要に応じて運営者がGmail上で添付を確認する場合があります。

ローカルAIによる補助と人による返信

処理用コピーをDrive Desktopで運営者管理のWindows端末へ同期し、ローカルAIモデル（Ollama）で一次分類、内容整理、不具合調査の補助、返信案の作成を行う場合があります。問い合わせ内容を外部のクラウドAI APIへ送信しません。これは、GmailやGoogle Driveを問い合わせの送受信・保存・処理用同期に利用しないという意味ではありません。

解析結果はDrive経由でGmailの返信下書き作成に利用します。返信案が自動生成される場合も自動送信は行わず、運営者が内容・宛先・妥当性を確認し、必要に応じて修正してから手動送信します。

到着通知とソースコードを使う調査

問い合わせ到着を運営者へ通知するため、LINE Messaging APIを利用する場合があります。通知は新しい問い合わせの到着を知らせる固定文とランダムな管理番号に限り、送信者の氏名・メールアドレス、件名・本文、添付名・内容、製品名、Gmailの識別情報、ソースコード、AIの出力を含めません。

不具合調査の補助に、運営者端末へ取得したGridPorterのソースコードを参照する場合があります。問い合わせ情報をGitHubの公開Repository・Issue・commit・PRへ自動投稿・保存しません。ソース更新の通信に問い合わせ内容を付けて送ることもありません。

サポート情報の保存期間と削除

Drive上の処理済みコピー・結果等は最終更新から原則7日、失敗した処理項目は最終更新から原則30日を目安にゴミ箱へ移します。未処理・処理中・回収待ちの項目は処理完了まで残る場合があり、整理処理の実行時期・件数制限等によって削除が遅れる場合もあります。重複処理防止等のため、本文を含まない管理番号・識別情報・処理状態をより長く保持する場合があります。

ゴミ箱への移動は即時の完全消去ではありません。Google側の履歴・ゴミ箱・バックアップ、同期した端末等に一定期間残る可能性があります。

Gmail上の問い合わせ原文・添付・返信下書き・返信履歴は、問い合わせ対応や不具合調査等に必要な期間、サポート用メールボックスで管理します。現在の自動処理はこれらを自動削除しません。不要となった情報は運用上の判断により削除します。Extension内のDataset等の保存期間とは別の管理です。取扱いや削除のご相談はサポート窓口へお寄せください。

6. Extensionのセキュリティ

実行コードは拡張機能に同梱し、認証・CAPTCHA・アクセス制限を回避しません。保存先はブラウザープロファイル内の拡張機能用ストレージであり、暗号化保管庫やOS上の安全な消去を提供するものではありません。共有端末では保存期間と手動削除を確認してください。ブラウザーやOSを更新し、出力先・共有先も利用者自身で確認してください。

7. このWebサイトについて

本サイトは静的サイトです。サイトのコードではCookie、アクセス解析、広告、外部JavaScript、外部フォームサービスを使用しません。拡張機能内のデータを読み取る機能もありません。

GitHub Pagesで配信する場合、アクセス時のIPアドレス等は配信事業者であるGitHubにより処理されることがあります。これは拡張機能による抽出データの送信とは別です。詳しくはGitHubのプライバシーステートメントをご確認ください。

8. ポリシーの変更とお問い合わせ

製品や情報の取扱いが変わる場合、このページと最終更新日を更新します。新たなデータの利用・送信等については、必要な説明と同意の手続きを行います。

データの取扱いと削除についてはサポートガイドをご覧ください。
