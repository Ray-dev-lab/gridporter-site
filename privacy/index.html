1. 対象と基本方針

このポリシーは、Chrome拡張機能「GridPorter」と本公式Webサイトにおける情報の取扱いを説明します。GridPorterの目的は、利用者が選択したWebの表・一覧を取得し、確認・整理してExcelなどへ出力することです。

Local-firstを基本とし、抽出したWebデータ・ページURLを開発者サーバーへ自動送信しません。アカウント登録、Analytics SDK、広告、AI APIへの送信、販売目的のデータ売却はありません。

GridPorterは、Chrome Web StoreのUser Data Policy（Limited Use要件を含む）に従い、利用者の情報の利用を、ここに開示した表・一覧の取得・確認・整理・出力と関連する機能の提供に限定します。閲覧履歴全体を追跡する目的では利用しません。広告配信、データ仲介、信用評価や融資のために情報を利用・移転・販売しません。

2. 取り扱う情報と保存目的

利用者の操作に応じ、次の情報をブラウザー内で処理します。選択したページの情報には個人情報や業務上の機密情報が含まれる場合があります。

情報内容と利用目的保存場所
Website content選択した表・一覧の文字、リンク・画像URLと代替文字、一部非機密フォームの現在値。取得・編集・出力に使用。画像本体は収集しません。処理中のメモリー、Dataset
URL・タイトル取得元の識別、ページ送り、Recipeの再利用、任意の取得情報シートに使用。Dataset、Recipeなどの関連データ
RecipeURL条件、取得条件・セレクター、列・整形設定、Repair用の列名や見出し等の署名。繰り返し作業に使用。chrome.storage.local
Dataset取得行・列、編集前の元データなど。プレビュー・編集・出力に使用。IndexedDB。保存しない設定ではchrome.storage.session
Snapshot比較に必要な列ID・列名と値などを明示保存。前回結果との比較・差分出力に使用。IndexedDB
checkpoint・一時データ長い取得の途中結果、プレビュー用の一時保持。途中結果の確認に使用。自動再開は行いません。IndexedDB、chrome.storage.session、画面のメモリー
設定・ローカル利用カウンター保存期間等の設定、出力・Recipe実行の成功回数、レビュー案内済みフラグ。機能設定・案内の表示に使用。カウンターにはページ・URL・セル値を含めません。chrome.storage.local。外部集計なし

パスワード・hidden入力や認証を示す入力などを取得対象から除外します。ただし一般の表や入力欄に含まれる機密情報を自動で検出・除去できることを保証しません。

3. 保存期間と削除方法

抽出データと途中結果

  • Datasetは「保存しない・1日・7日」から選択でき、既定は7日です。「保存しない」場合もプレビュー用にセッションストレージへ全体8MBまで一時保持し、表示中の画面にもメモリー上のデータが存在します。
  • セッションのデータはブラウザー再起動や拡張機能の無効化・再読み込み等で失われ得ます。「保存しない」はデータの即時消去を意味しません。
  • checkpointは1日、最大10件・全体20MBです。「保存しない」設定では永続保存しません。
  • 期限判定は利用時・起動時に行います。ブラウザーを使用していない間の指定時刻での消去を保証しません。
  • 保存期間短縮の確認時に期限超過分を削除します。「保存しない」に変更すると既存の永続Dataset・checkpointを削除します。

比較履歴は別管理です

任意保存のSnapshotは「30日・90日・365日・削除するまで」から選択でき、既定は90日です。Recipeごとに最大5件、1件20MB・全体40MBです。容量超過時は保存を拒否し、比較基準を容量整理のために自動削除しません。期限判定は比較・履歴の利用時に行い、期限が過ぎた基準は削除対象になります。

Datasetの「保存しない」や削除操作はSnapshotに影響しません。比較履歴の管理画面で個別削除・全削除・保存期間変更ができます。期間短縮では期限超過の基準も削除されます。旧Snapshotの期限を移行時に自動延長しません。

手動削除と出力済みファイル

設定画面で一時取得データ（Dataset・checkpoint・セッション）と比較履歴をそれぞれ削除でき、両方を削除する操作も別途確認します。RecipeはRecipe管理から削除できます。Recipe・設定・ローカル利用カウンターは手動削除できる項目を除き、拡張機能のアンインストールまで端末内に保持します。

任意設定の「Excel/CSV保存後に抽出データを削除」は保存完了後にDataset・checkpointを削除します。Recipe・Snapshot・開いているプレビューのメモリー・ダウンロード済みファイルは消しません。開いているプレビューは作業後に閉じ、出力ファイルや貼り付け先のデータは利用者自身で管理・削除してください。

4. 送信・第三者共有と対象サイトへの通信

開発者への自動送信はありません

抽出内容・URL・Recipe・Dataset・Snapshotを開発者や広告・分析事業者へ自動送信しません。開発者は端末内の抽出データを閲覧できません。データを第三者に販売せず、広告目的で共有しません。

対象Webサイトへの通常通信

次ページの取得は、利用者が指定した同一サイトへの通常のGET通信を行い、対象サイトのセッションを利用します。「もっと見る」ボタンやスクロール操作は、対象サイト自身の通信を発生させる場合があります。Cookie値を取り出して保存する機能ではありません。対象サイトによる情報の取扱いは、そのサイトの方針をご確認ください。

出力・Recipe転送・サポートでの明示的な共有

XLSX・CSV・コピーは利用者の明示操作で作成します。任意の取得情報シートにはタイトル・URLパス等、差分シートには変更前後の値が入り得ます。Google Sheets等への貼り付け先やファイルの共有先では、そのサービスの方針が適用されます。

RecipeのImport / Exportは利用者が指定したファイル操作です。URL・セレクター・列名・見出しなどに業務情報が含まれ得ます。共有前に内容を確認してください。Import直後の自動取得は行いません。Repair用の情報も端末内に保持します。

サポート情報は利用者が明示的にコピーし、共有先を選びます。バージョン、取得モード、終了理由、行列数、診断コード、境界種類等を含み、本文・セル値・Cookie・認証値・セレクター文字列は含みません。URLは利用者が選択した場合のみ入り、認証情報・クエリ・フラグメントを除外します。ただしパス自体にも機密情報が含まれる場合があります。

お問い合わせ時に利用者自身が送った連絡先・本文・添付資料は、回答と問題調査のために取り扱います。メール等で送信する際はそのサービス提供者も通信を処理します。必要な範囲に絞り、秘密情報を送らないでください。

5. セキュリティ

実行コードは拡張機能に同梱し、認証・CAPTCHA・アクセス制限を回避しません。保存先はブラウザープロファイル内の拡張機能用ストレージであり、暗号化保管庫やOS上の安全な消去を提供するものではありません。共有端末では保存期間と手動削除を確認してください。ブラウザーやOSを更新し、出力先・共有先も利用者自身で確認してください。

6. このWebサイトについて

本サイトは静的サイトです。サイトのコードではCookie、アクセス解析、広告、外部JavaScript、外部フォームサービスを使用しません。拡張機能内のデータを読み取る機能もありません。

GitHub Pagesで配信する場合、アクセス時のIPアドレス等は配信事業者であるGitHubにより処理されることがあります。これは拡張機能による抽出データの送信とは別です。詳しくはGitHubのプライバシーステートメントをご確認ください。

7. ポリシーの変更とお問い合わせ

製品や情報の取扱いが変わる場合、このページと最終更新日を更新します。新たなデータの利用・送信等については、必要な説明と同意の手続きを行います。

データの取扱いと削除についてはサポートガイドをご覧ください。
