# 架空の価格改定確認サンプル

すべて架空データ。実注文・顧客・取引・ライセンス・秘密情報を含みません。現行GridPorterの共通処理で生成し、CSV/ZIP/XMLで独立再読込しました。実Excelの表示試験や顧客の時短実測ではありません。

- previous.csv / current.csv：前回/今回の仕入価格表、各5行。
- master.csv：自社商品マスタの別入力例。00123の原価1100で、前回価格表1000とは別です。サンプル確認資料はこのmaster.csvの更新結果ではありません。
- confirmation-sample.xlsx：前回→今回。警告なしのペン500→450だけを承認。ノート1000→1500と品名空欄の消去はREVIEWで保留。9シートに全件の判定/集計/条件があります。
- proposal-sample.csv：上記1セルだけを反映した更新案。元ファイル/外部サービスへの反映ではなく、EC専用CSVでもありません。
- blocked-current.csv / blocked-report.xlsx：重複・欠損・税/単位等の危険例。危険例の設定では在庫更新の保護違反も含み、BLOCKにより更新案を生成しません。正常例と判断条件が同一ではありません。
- manifest.json：配布ファイルのサイズとSHA-256。改ざん検出用の比較値であり、販売ライセンスや発信元の署名ではありません。

商品コードの先頭0と20桁文字列、在庫/保護列を保持しています。CSVは型を持たないためExcel側でコード列を文字列として取り込んでください。CSVを直接開いた結果の数字変化を、元ファイルの値と混同しないでください。

月次照合と資料生成はFounderの機能です。Freeは単体取込・整形・出力等を提供する構成で、このサンプルがFreeの月次照合機能を意味するものではありません。現在は一般公開前・未販売です。
