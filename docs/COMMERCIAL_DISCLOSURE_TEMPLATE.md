# 将来の有料販売に向けた表示項目

販売開始前に事業形態・販売地域・適用法令を確認して人間が確定するためのテンプレートです。現時点で有料販売は行いません。公開HTMLからはリンクしません。Public repository内なので、このファイル自体は機密ではありません。個人情報を入力する前に公開範囲を判断してください。

|項目|入力・確認する内容|
|---|---|
|販売事業者|正式な事業者名|
|運営責任者|責任者の正式名称|
|所在地|表示が必要な所在地、適用可能な開示方法|
|電話番号|有効な連絡番号、受付条件|
|問い合わせ先|有効なメール等、受付時間、対応方針|
|販売価格|税込表示、通貨、プランごとの金額|
|価格以外の負担|通信費、手数料、税等の有無|
|支払方法|利用可能な手段、決済事業者|
|支払時期|初回・更新時の請求時点|
|提供時期|ライセンス発行・機能利用開始の時点|
|自動更新|有無、更新周期、更新価格、通知|
|解約方法|受付方法、期限、効力発生時期、解約後の機能|
|返金|条件、対象外条件、受付期間、手続き|
|動作環境|Chrome / OS / 必要条件、制約|

決済・購入ボタンを追加する前に、公開用の表示ページ、Privacy・Terms、問い合わせ窓口を整備してください。現時点で事業者名・価格等は推測していません。
