# 実画面の準備

第一候補は **1280×800 px**。Chrome Web Storeにも流用しやすい横長の実画面を用意します。最新版のStore提出要件は提出時に別途確認してください。

|ファイル名|見せる操作|
|---|---|
|01-web-to-excel.png|表の選択からプレビュー・Excel保存まで|
|02-card-list.png|商品・求人等のカード型一覧取得|
|03-diagnostics.png|取得完了度・診断・確認が必要な箇所|
|04-japanese-normalization.png|価格・数字・日付の整形前後|
|05-compare.png|比較基準・追加・変更・削除の確認。Pro βと明示|

1. 自作の公開可能なサンプルページ・データを使い、実際の拡張機能で操作します。
2. 個人情報、アカウント、認証情報、閲覧履歴、業務機密、URLの機密パス・クエリ、他社ロゴ・権利を確認します。
3. 文字が読める構図にし、ブラウザー内の余分なタブやデスクトップを含めないでください。
4. 架空の拡張機能UIを生成・合成して実画面として掲載しないでください。
5. 画像を `assets/screenshots/` に配置し、設定のscreenshots配列へ実在ファイルのみ登録します。

```js
screenshots: [
  { src: 'assets/screenshots/01-web-to-excel.png', alt: '表の取得結果を確認してExcelへ保存するGridPorterの実画面' },
],
```

ファイルが存在しロードに成功した場合だけトップページへ表示します。空配列ではセクション自体が非表示です。画像追加後は表示・alt・ファイルサイズ・モバイル可読性を確認してください。現在は実画像を同梱していません。
