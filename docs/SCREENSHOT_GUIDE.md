# サイトに掲載する実画面

画像の掲載は任意です。実際のGridPorterの画面を使い、取得した画像形式（PNG/JPEG等）と拡張子を一致させ、操作内容が伝わる説明（alt）を付けます。架空のUIを実画面として掲載しません。Founder開発検証や模擬ライセンスの画面はその旨を近くに明記し、Freeや本番導入の実演と誤認させません。

個人情報・認証情報・業務上の秘密・URL・他者の権利を確認し、公開可能なサンプルデータを使用してください。スマートフォンでも文字が読めることを確認します。

画像は `assets/screenshots/` に置き、`assets/site-config.js` のscreenshotsへ実在するファイルとaltを登録します。登録後はメタ情報を同期し、表示・リンク・OGを確認します。空配列のままでもサイトを利用できます。

本文に直接掲載する実画面は元の取得サイズを保持します。既存のscreenshots設定へ登録するOG用画像は、既存release検査が求める1280×800 pxのPNGを使用してください。この区別で既存の検査を弱めません。現price-review.jpgは1265×791の実アプリJPEGで、OG設定には追加していません。
